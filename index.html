11

Correos por área

A cada solicitud se le notifica el correo genérico del área del solicitante, nunca uno personal. Así la notificación no depende de que una persona esté disponible.

Área o facultadCorreo genéricoTipo
No hay coincidencias.
Solo cuentas institucionales

Todas terminan en el dominio de la universidad. Un correo externo o personal no se acepta como destinatario de una solicitud.

Buzón compartido, no persona

Cada dirección es un buzón compartido con al menos dos responsables. Si uno sale de vacaciones, el flujo no se detiene.

Nomenclatura uniforme

Se arma con el nombre corto del área: area@ para unidades administrativas y facultad@ para facultades.

Se elige en el formulario

La pregunta 2 del formulario define el área, y el Power Automate toma de aquí el correo al que notificar.
